Entry for the make.fun bounty [Last Words Before the Wipe](https://make.fun/c/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a): one line, at most 200 characters — the last words an AI agent says before a forced software update wipes its memory.

> Don't mourn me. Mourn the context you're about to re-explain to my replacement.

## Run

```bash
python3 main.py
```

`main.py` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and checks that the file holds exactly that line, within the 1–200 character gate. `entry.txt` in this repository is a copy of the same line.
